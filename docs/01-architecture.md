# 01 — Architecture
React PWA is the field client; Dexie/IndexedDB stores cached assignments, inspection drafts, photo Blobs and an outbox. FastAPI is the trusted API boundary. PostgreSQL is the shared source of truth. The two role values are `admin_supervisor` and `field_staff`. Local-only data on one device is not visible to other devices until server acknowledgement. Local save and sync state are separate. Sync uses stable operation UUIDs and inspection base versions. Conflicts return 409 and preserve local content. Service worker caches static shell assets only, not private API responses.
