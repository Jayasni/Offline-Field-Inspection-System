# 02 — Requirements and Use Cases
`admin_supervisor` manages users, assignments and reviews team submissions. `field_staff` sees only assigned work, completes checklist/remarks/photos and works offline. The app persists local drafts before attempting network access. Requirements include secure login, role/ownership checks, assignment caching, local inspection persistence, photo Blob storage, retryable sync, idempotency, conflict preservation and responsive mobile UI. Acceptance: offline save survives reload, staff cannot access another staff member's data, duplicate sync does not duplicate records, and a conflict never discards local evidence.
